Draft Only, Never Send: Hardening AI-Assisted Workflows in a University Research Lab

Joseph Benjamin Ilagan, Gabrielle Anne Uy, Jose Ramon Ilagan

IEEE Software, 2026.

Download PDF (accepted manuscript) Published version (IEEE)

Abstract

AI-assisted workflows often start as open-ended prompting and end up as deterministic scripts. This report describes that shift in two workflows we built in a small university lab in early 2026: a geospatial classification pipeline over about 3,000 establishment records, and a reimbursement workflow that once sent an email we did not mean to send. One hardened because of cost, the other because of risk, but both the same way: we used a capable model to write explicit checks and guardrails, then let cheaper models or plain scripts run inside them. In software-engineering terms, the result is an execution harness around an unreliable component. That construct is old news. What we think is worth reporting is how the harness came together after the fact, in a lab that never meant to build one, and which failures are specific to a multi-model setup, where knowing which model actually acted matters for forensics and is almost never logged.

Keywords: agentic workflows; AI hardening; agent harness; multi-model routing; LLM deployment; software engineering practice
